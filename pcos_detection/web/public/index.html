      Indexed documents

        Retrieval-augmented generation

        Each request is embedded and matched against the index. Only retrieved passages go to the LLM, which must cite them as [S1], [S2]. Passages and similarity scores are shown under every answer.

        Prompt engineering

        System prompts encode the Rotterdam criteria, safety rules (never diagnose) and strict JSON output schemas for the screening report, tips and wellness plans.

        Reliability

        Two LLM providers with retry and automatic fallback, a rule-based image pre-check, a stronger vision model, and a WhatsApp channel through Twilio.

        Limitations and future work

        • Screening levels come from an LLM following guideline rules. They are not calibrated probabilities.
        • Cycle predictions and fertile windows are calendar estimates and are unreliable with irregular cycles. Never use them for contraception.
        • Future work: add trained ML models (a symptom classifier and a validated ultrasound model) alongside the LLM, trained on clean, representative clinical data.
        • User accounts and cloud sync are planned. Today all personal data stays in the browser.

        Educational project. Not a medical device and not a diagnosis. Always consult a qualified clinician.
